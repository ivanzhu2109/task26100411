# sentinelcore

跨域检测规则的滑动时间窗证据关联匹配库（Go）。只负责窗口内互异证据关联，
不含接口服务、事件持久化与调查流程。

## 模型

- `Rule`：1..12 个有序 `Slot`，每个槽位限定 `Domains`（空为任意）、`MinSeverity`、`Tags`（须全部包含）。
- `Event`：`EventID`（全局唯一）、`EntityID`、`Timestamp`（毫秒）、`Domain`、`Severity`、`Tags`。
- 时钟为 `t` 时，活跃事件满足 `t-W < Timestamp <= t`。
- 命中：同一实体存在一种完整分配，把每个槽位分给窗口内满足条件的不同事件。
- 每个实体仅在“不满足 -> 满足”沿产生一次告警；失配后重新满足会再次告警。

## 接口

```go
eng, err := sentinelcore.NewEngine(rule, windowMs) // 规则 1..12 槽位，W>0
alerts := eng.Ingest(ev)   // 推进时钟->处理到期->加入事件；返回新增告警（0 或 1 条）
eng.Advance(t)             // 只推进时钟并处理到期
evidence, ok := eng.Match(entityID) // 当前一组完整证据（按槽位排列）
```

- `Ingest` 的到期与加入是两个有序阶段：同时间先失配再恢复会产生新告警。
- `Alert.Evidence` / `Match` 的返回值均按槽位顺序给出 `event_id`，证据不保证唯一但真实有效。
- 调用方保证：单线程、输入时间全局非递减、事件已规范化。

## 实现要点

- 每实体维护增量二部匹配（Kuhn 增广，槽位 <=12）：事件增删时只沿增广路局部调整，
  不重扫窗口重建匹配，也不枚举组合。
- 槽位候选集 + 匹配指针使热点实体的大量可互换证据下补位为近似 O(1)。
- 全局 FIFO 到期队列按序弹出实际到期项，不遍历存活事件或实体。
- 实体窗口清空即回收其全部内部状态；状态量只随窗口内事件与活跃实体数增长。
