# SentinelCore 跨域检测规则匹配库

单规则、滑动时间窗内的互异证据关联匹配。纯内存库：无接口服务、无持久化、无调查流程。

## 模型

- `Rule`：1–12 个**有序槽位**，每个槽位限定 domain 集合、severity 下限、必须全包含的 tags。
- `Event`：已规范化的事件（`ID` 全局唯一，`EntityID` 已由上游统一解析），含 `Timestamp`（毫秒）、`Domain`、`Severity`、`Tags`。
- 时钟为 `t` 时，活跃事件满足 `t-W < Timestamp <= t`（`W` 为窗口毫秒数）。
- 命中 = 存在一种完整分配：每个槽位分到窗口内满足其条件的**不同**事件（同一事件至多占一个槽位，不同实体的事件不混用）。
- 实体仅在「不满足 → 满足」跳变时告警一次；持续满足不重复告警；失配后重新满足再次告警。

## 接口

```go
eng, err := sentinelcore.NewEngine(rule, windowMs) // 规则 1..12 槽位，windowMs > 0
alert := eng.Ingest(ev)      // 推进时钟→处理到期→加入事件；命中跳变时返回 *Alert（含按槽位排列的证据 ID），否则 nil
eng.Advance(t)               // 只推进时钟、处理到期（无新事件时清理状态）
evidence, ok := eng.Match(entityID) // 当前一组真实有效的证据（按槽位序），或 ok=false
```

调用约定：单线程；输入时间戳全局非递减。`Ingest` 内「到期处理」先于「加入事件」，因此同一时间戳上先失配再恢复会产生新告警。

## 实现要点

- 每个实体维护一份槽位↔事件的**增量二部最大匹配**：新增事件最多让匹配数 +1（从空槽位找增广路）；匹配事件到期时从被释放的槽位重新找增广路。不枚举组合、不重扫窗口。
- 每槽位一个按时间有序的候选队列（惰性跳过已匹配项、到期时从前端精确弹出），加上 ≤12 项的已匹配邻接表；增广搜索代价与窗口内事件总数无关。
- 全局 FIFO 到期队列按时间序逐项弹出，不遍历存活事件或实体；实体窗口清空即删除其全部状态，内存随窗口规模而非历史总量增长。

## 测试

```sh
go test ./...                    # 单元 + 差分 + 压力测试
go test -short ./...             # 跳过百万级压力测试
go test -run TestStress -v .     # 只看压力测试（耗时/峰值内存日志）
```

- `engine_test.go`：重叠槽位贪心失败、Hall 违背（逐槽位有候选但无完整分配）、证据到期替换、窗口边界严格性、同时间戳先失配再恢复、`Advance` 清理、实体隔离、槽位约束。
- `differential_test.go`：固定种子随机操作序列，与穷举回溯参考实现逐次核对可满足性、告警次数与证据有效性。
- `stress_test.go`：100 万事件、峰值 30 万活跃、1 万实体、12 槽位、80% 流量集中于单实体；含稀有证据不足的长期失配阶段与反复到期补入；记录耗时与峰值内存，并验证窗口排空后状态全部回收。
